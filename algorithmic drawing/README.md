

Pour mon projet, j'ai choisi de représenter un mur d'yeux qui fixent le curseur de la souris en p5.js. J'aime bien le concept, ça me fait penser à une forme de surveillance, un sentiment d'oppression.

Le projet a été testé sur l'éditeur web de p5 : https://editor.p5js.org/
Il utilise les fonctions 3D de p5, et a été inspiré par ce tutoriel que j'ai trouvé dans les docs : https://p5js.org/tutorials/lights-camera-materials/
